# BridgePay — Mock Credit Bureau

Stands in for a real credit bureau. Stateless, no datastore: it hashes the applicant id into a
fixed in-memory pool of 22,500 real (held-out) rows of the Kaggle *Give Me Some Credit* dataset and
returns that row every time. The same applicant always gets the same profile.

## Where the pool comes from

`src/main/resources/data/bureau-pool.csv` is generated by `scripts/generate_pool.py` from the raw
dataset, using the held-out split rule `rowIndex % 100 < 15` (see [`data/README.md`](../../data/README.md)).
The model's training script applies the same rule to exclude these rows, so the bureau never serves
a profile the model was trained on.

Cleaning (imputation statistics computed from the other 85% only): median-impute missing
`MonthlyIncome`, 0-impute missing `NumberOfDependents`, cap the dataset's 96/98 sentinel values in
the past-due columns to 18, and clip the one `age == 0` row to 18.
